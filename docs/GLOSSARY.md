# Glossary

| Term | Full name | Meaning in OptiLink |
|---|---|---|
| ADR | Architecture Decision Record | A durable record of an important architecture decision, its context and consequences. |
| PR | Pull Request | A proposed change from a branch into another branch, normally reviewed before merge. |
| CI | Continuous Integration | Automated checks run by GitHub Actions on pushes/PRs. |
| CD | Continuous Delivery/Deployment | Automated packaging or publishing after checks succeed. |
| MVP | Minimum Viable Product | Smallest product version sufficient to validate key user/product assumptions. |
| Spike | Agile technical spike | Time-boxed investigation/experiment used to reduce uncertainty before committing to implementation. |
| Epic | Epic | Large body of work composed of stories/tasks. |
| Story | User Story | Small user-oriented unit of value. |
| Task | Task | Concrete work item. |
| Subtask | Subtask | Smaller execution step under a task. |
| Gate | Review Gate | Explicit owner approval checkpoint before the project advances across a high-impact decision. |
| QR | Quick Response Code | Standard 2D barcode considered as an initial optical carrier. |
| FEC | Forward Error Correction | Adds redundancy so the receiver can recover some lost/corrupted data without retransmission. |
| CRC | Cyclic Redundancy Check | Error-detection checksum used to detect corrupted data. |
| Net goodput | — | Correctly reconstructed original data divided by elapsed transfer time; excludes protocol/encoding overhead. |
| Air-gapped | — | Systems intentionally isolated from normal network connectivity. |
| CameraX | Android Jetpack CameraX | Android camera library considered for the native receiver. |
| PWA | Progressive Web App | Web application that may support installation/offline use while retaining a browser-based technology base. |
