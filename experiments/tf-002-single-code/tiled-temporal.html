OptiLink · TF-007 Phase A2 · combined gate

Combined spatial degradation + rolling-shutter simulation

Three independent horizontal OptiGrid tiles are rendered into a full 1920×1080 frame. This gate combines stronger scale/rotation/shear/blur/noise degradation with a 60 Hz camera that reads top→bottom across a configurable fraction of the frame period, so a camera image may contain adjacent optical symbols. The Receiver sees only the composed/degraded ImageData; no Sender payload, cell arrays, exact tile geometry or Sender-derived locks are passed across the boundary.
