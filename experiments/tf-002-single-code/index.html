Performance baseline: 从本版本开始，当前测试显示器按 60 Hz 物理刷新率记录；OptiLink QR 视觉更新率是独立参数。此前 Auto Lab 轮次仅作为功能/测试链路验证，不作为工具性能结论。

Auto Lab: 网络只用于实验控制与遥测，文件 payload 仍只通过屏幕 → 摄像头传输；正式离线验收会关闭该控制通道。
